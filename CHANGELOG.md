# Changelog

Все заметные изменения в проекте документируются здесь.

## [2.0.0] - 2025-09-10
### Added
- Разделение проекта на модули:
    - `app` — основной модуль с `MainActivity` и `NavGraph`.
    - `auth` — модуль авторизации, независимый от `app`.
    - `ui` — общий модуль с компонентами интерфейса (`CustomNavigationDrawer`, `CustomOutlinedTextField`, темы и стили).
    - `core-di` — общий модуль для предоставления зависимостей (`FirebaseAuth`, `DatabaseReference`, `UserPreferences`).
- Добавлен интерфейс `UserPreferences` для абстракции работы с пользовательскими данными.
- Создан `UserPreferencesImpl` для реализации интерфейса.
- Настроена работа `SPViewModel` через `UserPreferences` для независимости модуля `auth`.
- Обновлён `NavGraph` в модуле `app` с поддержкой бокового меню (`CustomNavigationDrawer`).
- Добавлена возможность подсветки и сохранения выбранного элемента в боковом меню.
- Подключение графа авторизации (`authNavGraph`) через интерфейс `UserPreferences` без прямой зависимости от модуля `auth`.
- Настроена тема приложения (`GeneralTheme`) в модуле `ui` и перенесены все элементы интерфейса (цвета, стили, `CustomTopAppBar`, текстовые поля).
- Добавлены функции навигации `navigateFunction` для модульной работы экранов.

### Changed
- Обновлён `MainActivity` для работы через `UserPreferences`, удалён прямой доступ к `SPViewModel`.
- Навигация в `MainActivity` и `NavGraph` полностью работает через интерфейс `UserPreferences`.
- Перенесена логика подсветки текущего маршрута и сохранения выбранного элемента меню в `CustomNavigationDrawer`.
- Рефакторинг зависимостей Hilt: устранены дубликаты `DatabaseReference` с использованием общего модуля `core-di`.
- Обновлены зависимости Compose и Firebase для корректной работы с модульной архитектурой.

### Fixed
- Исправлена подсветка выбранного элемента в боковом меню после перехода между экранами.
- Устранены дублирующиеся биндинги Hilt для `DatabaseReference` в модулях `app` и `auth`.
- Исправлены ошибки пересоздания состояния `ViewModel` и повторного доступа к `SPViewModel`.
